choudoufu

OpenTofu, with your platform holding the record of what you own.

A fork of OpenTofu that puts each resource's identity on the resource itself, where the platform's own policy engine can see it. Adopt what already runs, gate it with the policy you already have, and treat the state file as a cache you are allowed to lose.

Start with AWS How it works

Adopt live infrastructure

Point it at what already runs. Adoption is a marker written onto each resource, not a state migration; a plan run before the markers are on reads the resource as absent, proposes a duplicate, and says so before you apply.

Gate with the platform's own policy

Ownership is a marker the platform can select on, so its policy engine decides who may change what, per resource. Handover is a role grant. Splitting an estate is a retag. No lock table, no bucket policy to keep in step.

Lose the state file

Identity lives on the resources, values in a record store, effects as receipts. The state file is a projection of those three; delete it and the next plan rebuilds it from live reads, with the same answer.
