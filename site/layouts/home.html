choudoufu

OpenTofu, with your platform holding the record of what you own.

OpenTofu keeps a state file that says what you own. choudoufu writes that onto the resources themselves, as a marker your cloud's own access control can read. Adopt what already runs, decide who may change what with the policy you already have, and keep the state file only as a cache you may delete.

Start with AWS How it works

Adopt live infrastructure

Point it at what already runs. Adopting a resource means writing a marker onto it. A plan run before the markers are on reads the resource as absent, proposes a duplicate, and says so before you apply.

Gate with the platform's own policy

Ownership is a marker the platform can select on, so its policy engine decides who may change what, per resource. Handover is a role grant, splitting an estate is a retag, and there is no lock table.

Lose the state file

A marker on every resource says who owns it, and a small record per resource holds what cannot be read back. The state file stays as a cache: delete it and the next plan reads the live system and gives the same answer.
