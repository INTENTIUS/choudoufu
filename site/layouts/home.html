choudoufu

Your cloud already knows what you own.

choudoufu is OpenTofu that tags each resource with its owner. Your cloud's own permissions decide who can change it.

Start with AWS How it works

Adopt what already runs

Tag a resource and your configuration owns it. One command tags everything in an existing state file.

Use the permissions you have

An ordinary policy on the tag decides who can change a resource. Handing over an estate is granting a role.

The state file is a cache

Plans read your live resources and the tags on them. Delete the cache and the next plan gives the same answer.
