A resource is yours once it carries the tags `tofu-estate` and `tofu-address`.

## The bulk path

```
choudoufu live-import -state=stock.tfstate -estate=my-estate -approve
```

Run it before the first apply. It tags every state entry that matches its live object. Keep the state file until the next plan is empty.

## What binds on its own

Tagged and named resources bind on the first plan.

## Leaving

Copy `.terraform/choudoufu-cache.tfstate` to `terraform.tfstate` and delete `estate.chdf.hcl` ([Undo](/choudoufu/docs/use/migrate/#undo)).
