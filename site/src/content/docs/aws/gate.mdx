The create call writes the tag, so a role can be scoped by it.

```json
{
  "Sid": "MutateOnlyThisEstate",
  "Effect": "Allow",
  "Action": ["ec2:CreateTags", "ec2:DeleteTags", "ec2:TerminateInstances"],
  "Resource": "*",
  "Condition": {
    "StringEquals": {"aws:ResourceTag/tofu-estate": "prod-networking"},
    "StringEqualsIfExists": {"aws:RequestTag/tofu-estate": "prod-networking"}
  }
}
```

## What that buys

Handing an estate over moves this policy to the new role, and plain `aws` calls meet the same fence.

## Guarding the marker

An SCP that denies the untag actions keeps the tag on every resource in the account ([GOVERNANCE.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/GOVERNANCE.md)).
