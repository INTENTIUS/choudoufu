The marker is a tag written with the create call, so a role can be scoped by it.

```json
{
  "Sid": "MutateOnlyThisEstate",
  "Effect": "Allow",
  "Action": ["ec2:CreateTags", "ec2:DeleteTags", "ec2:TerminateInstances"],
  "Resource": "*",
  "Condition": {
    "StringEquals": {"aws:ResourceTag/tofu-estate": "prod-networking"},
    "StringEqualsIfExists": {"aws:RequestTag/tofu-estate": "prod-networking"}
  }
}
```

`aws:ResourceTag` covers existing resources. `aws:RequestTag` covers creates.

## What that buys

Handing an estate over moves this policy to the new role. Splitting one is `choudoufu live-mv -from-estate=<old> <address>`. The fence binds the credential, so plain `aws` calls meet it too.

## What it cannot reach

Types with no tag surface fall outside the grant ([IAM-REFERENCE.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/IAM-REFERENCE.md)). An SCP denying the untag actions protects the tag itself ([GOVERNANCE.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/GOVERNANCE.md)).
