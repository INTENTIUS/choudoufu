## Rename

`choudoufu live-mv <old> <new>` or a `moved` block rewrites the `tofu-address` tag ([Rename](/choudoufu/docs/use/rename-a-resource/)).

## Remove

Delete the block to destroy the object. The [ownership policy](https://github.com/INTENTIUS/choudoufu/blob/main/live/OWNERSHIP-POLICY.md) releases it instead ([Remove](/choudoufu/docs/use/remove-a-resource/)).

## Scale

Pool members carry a `tofu-slot` tag.

## Plan, review, apply

`apply FILE` applies a saved plan that still matches the live system, and exits 3 otherwise.

## From CI

See the [CI how-to](/choudoufu/docs/use/cicd/).

## Two runs at once

Each create carries its tags, so the next plan sees the other run's objects ([CONCURRENCY.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/CONCURRENCY.md)).
