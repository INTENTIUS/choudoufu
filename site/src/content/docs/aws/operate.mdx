Day two is stock OpenTofu with tag writes in place of state moves ([Day-2 operations](/choudoufu/docs/use/day2/)).

## Rename

A `moved` block or `choudoufu live-mv <old> <new>` rewrites the `tofu-address` tag ([Rename a resource](/choudoufu/docs/use/rename-a-resource/)).

## Remove

Deleting the block destroys the object. The [ownership policy](https://github.com/INTENTIUS/choudoufu/blob/main/live/OWNERSHIP-POLICY.md) releases it instead. Its `threshold` caps deletes per run ([Remove a resource](/choudoufu/docs/use/remove-a-resource/)).

## Scale

Pool members carry a `tofu-slot` tag, so scaling touches the instances stock would.

## Plan, review, apply

`apply FILE` applies a saved plan only if it still matches the live system. Otherwise it exits 3 with `The approved plan no longer matches the live system`.

## From CI

Pull requests run `live-check` and `live-plan`. Approvals gate `live-apply` and `live-adopt`. A cron runs `live-discover` ([CI how-to](/choudoufu/docs/use/cicd/)).

## Two runs at once

Each create carries its tags, so the next plan sees the other run's objects ([CONCURRENCY.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/CONCURRENCY.md)).
