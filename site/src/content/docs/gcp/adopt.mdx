A resource is yours once its `labels` carry `tofu-estate` and `tofu-address`, an encoding of its address. Both go on with the create call.

## The bulk path

```
choudoufu live-import -state=stock.tfstate -estate=my-estate -approve
```

Without `-approve` it previews. Approved, it writes the labels through a labels-only plan. It refuses resources labelled for another estate.

## What binds on its own

The network skeleton has no labels map. It binds by the name, project and location you declare.

## Leaving

Drop the `live` block and keep the cache file. Stock OpenTofu carries on ([ADOPT.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/gcp/ADOPT.md)).
