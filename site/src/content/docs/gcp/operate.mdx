## Rename

Rename the block and plan. The plan rewrites the address label in place. `live-mv` refuses GCP resources for now.

### Records

```hcl
record_store "gcs" {
  bucket = "my-estate-records"
}
```

Use one bucket per estate. GCS cannot fence a listing.

## Remove

A labelled resource with your label and no block is proposed for deletion. GKE, Dataproc and Batch VMs and disks are excluded.

## Scale

A `count` set the server names carries `tofu-slot`, so scaling down keeps every survivor's index.

## Plan, review, apply

As on [AWS](/choudoufu/aws/operate/).

## From CI

The CI principal holds the project bindings the gate grants.

## Two runs at once

The record write is conditional, so the second apply is refused ([OPERATE.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/gcp/OPERATE.md)).
