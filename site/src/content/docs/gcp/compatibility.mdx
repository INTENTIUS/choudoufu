## The backend

Refused, as on [AWS](/choudoufu/aws/compatibility/).

## Expansions and identity arguments

Every expansion works. The address label is a fixed-length hash, so no key is too long.

## Resource types

Every `google_*` and `google-beta` type with a `labels` map carries the marker. The network skeleton binds by name and project. The sweep needs the Cloud Asset API enabled.

### Refused

| What | Fix |
|---|---|
| A marker label in an instance template | Remove it |
| An estate name over 63 characters | Shorten it |
| An unlabelled type the server names | Keep it outside the estate |
| `live-mv` | Rename the block and plan |

## Running it

`-target` and plan files work.

## Other providers

One estate per project. Two estates sharing a project are not fenced from each other ([COMPATIBILITY.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/gcp/COMPATIBILITY.md)).
