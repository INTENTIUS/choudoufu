## The backend

Refused, as on [AWS](/choudoufu/aws/compatibility/).

## Expansions and identity arguments

Every expansion works, because the label holds only the estate name.

## Resource types

Every `kubernetes_*` type with `metadata` works. Custom resources work through `kubernetes_manifest`. A manifest the API server rejects on dry run refuses the plan. `kubernetes_labels` and similar types mark by field manager `choudoufu:<estate>`.

### Refused

| What | Fix |
|---|---|
| `metadata.generate_name` | Set the name |
| A namespaced object with no `namespace` | Set the namespace |
| `helm_release` | Run Helm roots without a `live` block |
| A kind the cluster does not serve | Install its CRD |

## Running it

`-target` and plan files work.

## Other providers

An EKS module's `aws-auth` needs `declared_untagged = "adopt"` ([COMPATIBILITY.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/kubernetes/COMPATIBILITY.md)).
