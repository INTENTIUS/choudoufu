## The backend

Markers record ownership, so the configuration carries no `backend` or `cloud` block.

## Expansions and identity arguments

`count` and `for_each` work over data sources and over values the configuration states, such as variables and locals.

## Resource types

Every `kubernetes_*` type with `metadata` plans, and custom resources plan through `kubernetes_manifest`.

## Running it

`-target` and plan files work.
