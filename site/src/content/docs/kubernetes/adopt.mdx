An object is yours once it carries the `tofu-estate` label. A plan finds it by kind, namespace and name.

## The bulk path

```
choudoufu live-import -state=stock.tfstate -estate=my-estate -approve
```

Without `-approve` it previews. Approved, it writes the label and address annotation. It refuses objects labelled for another estate.

## What binds on its own

Every object binds by its natural key. Objects a controller made stay out of adoption. The label goes on with the create call.

## Leaving

`tofu state pull > stock.tfstate` from the `kubernetes` backend gives you the file. Delete that backend's Secret last ([ADOPT.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/kubernetes/ADOPT.md)).
