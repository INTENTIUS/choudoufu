## Rename

`live-mv <old> <new>` or the next apply rewrites the address annotation. `live-mv -from-estate` moves an object between estates.

### Records

```hcl
record_store "kubernetes" {}
```

Each record is a Secret in `tofu-records-<estate>`, a namespace you create. `choudoufu live-cluster` checks the setup and names each fix.

## Remove

An undeclared object with your label is proposed for deletion. Owner-referenced, control-plane and Helm release objects are excluded.

## Scale

Each instance's name is in its key.

## Plan, review, apply

As on [AWS](/choudoufu/aws/operate/).
