## Rename

`live-mv <old> <new>` rewrites the address annotation.

### Records

```hcl
record_store "kubernetes" {
  config_path = "~/.kube/config"
}
```

Each record is a Secret in `tofu-records-<estate>`. Install [the admission policy](/choudoufu/kubernetes/gate/) and run the API server with encryption at rest. On EKS, GKE or AKS, name the cluster so its encryption setting is read from the provider:

```hcl
record_store "kubernetes" {
  config_path = "~/.kube/config"
  control_plane "eks" {
    name   = "prod"
    region = "us-east-1"
  }
}
```

## Remove

An undeclared object with your label is proposed for deletion. Objects a controller or a Helm release made stay.

## Scale

Each instance's name is in its key.

## Plan, review, apply

`apply FILE` applies a saved plan that still matches the live system, and exits 3 otherwise.
