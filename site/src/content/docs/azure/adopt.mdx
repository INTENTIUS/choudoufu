A resource is yours once it carries `tofu-estate` and `tofu-address` in its `tags`. ARM tag keys are case-insensitive, so `Tofu-Estate` counts.

:::caution
An ARM create is a PUT that updates whatever is at its id. The plan stops by name at an unmarked resource on a declared id and never overwrites it, unless the policy admits it. Adopt it with `policy { declared_untagged = "adopt" }`, which writes the markers onto it in the plan.
:::

## The bulk path

```
choudoufu live-import -state=stock.tfstate -estate=my-estate -approve
```

Without `-approve` it previews. Approved, it writes both tags through a tags-only plan, into `body.tags` where an azapi block keeps its tags.

## What binds on its own

An azurerm block binds by the ARM id its template builds from `name`, `resource_group_name` and parents. An `azapi_resource` binds by `type`, `parent_id` and `name`. The subscription comes from the provider block.

## Leaving

`tofu state pull > stock.tfstate` from the `azurerm` backend gives you the file. Keep that blob until the plan is empty ([ADOPT.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/azure/ADOPT.md)).
