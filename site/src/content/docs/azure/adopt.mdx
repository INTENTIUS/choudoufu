A resource is yours once its `tags` carry `tofu-estate` and `tofu-address` in any case.

## The bulk path

```
choudoufu live-import -state=stock.tfstate -estate=my-estate -approve
```

Without `-approve` it previews. Approved, it writes both tags through a tags-only plan.

## What binds on its own

Every block binds by its ARM id. `policy { declared_untagged = "adopt" }` adopts an object already there.

## Leaving

Copy `.terraform/choudoufu-cache.tfstate` to `terraform.tfstate` and delete `estate.chdf.hcl` ([Undo](/choudoufu/docs/use/migrate/#undo)).
