## Claims you can run

Azure carries no claim cell. Each `az-*` script runs on the floci-az emulator, and under `BREAK=1` it must catch the injected fault; a script becomes a claim's proof with its first dated run. Two Azure estates, `reference-azure` and `corpus-azapi-role-assignment`, run every gauntlet stage on the same emulator.
