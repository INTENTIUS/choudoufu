An estate owns the resource groups it declares. As an Owner of the subscription, deploy two templates:

```
az deployment sub create --location <region> \
  --template-uri https://raw.githubusercontent.com/INTENTIUS/choudoufu/main/live/azure/estate-grant.json \
  --parameters estate=<estate> resourceGroups='["<rg>"]' principalId=<object-id>
az deployment sub create --location <region> \
  --template-uri https://raw.githubusercontent.com/INTENTIUS/choudoufu/main/live/azure/estate-boundary.json \
  --parameters estate=<estate> resourceGroups='["<rg>"]'
```

## What that buys

The grant gives one principal a role on those groups. Handing over moves the assignments, and `az` meets the same fence.

## Guarding the marker

The boundary Policy denies a write whose `tofu-estate` names another estate ([GATE.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/azure/GATE.md)).
