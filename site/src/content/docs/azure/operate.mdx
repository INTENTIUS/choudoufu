## Rename

`live-mv <old> <new>` or the next apply rewrites the `tofu-address` tag. The ARM id does not change.

### Records

```hcl
record_store "azurerm" {
  storage_account_name = "acmerecords"
  container_name       = "records"
  resource_group_name  = "records-rg"
}
```

Each record is a blob tagged with its estate. The account needs versioning, a previous-versions lifecycle rule and public access off ([CONTRACT.md](https://github.com/INTENTIUS/choudoufu/blob/main/examples/record-store-azurerm/CONTRACT.md)).

## Remove

An undeclared resource with your tag is proposed for deletion. The sweep is one Resource Graph query per subscription. Resources an AKS cluster or managed application owns through `managedBy`, or that carry an `aks-managed-` tag, are excluded. An attached disk's `managedBy` names its VM and does not exclude it.

## Scale

Each instance's address is in its tag. A `count` member also carries `tofu-slot`.

## Two runs at once

Record writes are conditional on the blob's ETag. Two plain applies to one resource leave the last write ([OPERATE.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/azure/OPERATE.md)).
