## The backend

Refused, as on [AWS](/choudoufu/aws/compatibility/).

## Expansions and identity arguments

Every expansion works, as on AWS. The subscription must be set in the provider block.

## Resource types

azurerm types plan when their ARM id template could be read, and so does every `azapi_resource`. [READINESS.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/READINESS.md#azure) lists every type short of that.

### Refused

| What | Fix |
|---|---|
| An azurerm type with no id template | Use `azapi_resource` |
| `declared_untagged = "keep"` or `"report"` | Use `"refuse"` or `"adopt"` |
| An azapi `body` unknown at plan time | Make it known |

## Running it

`-target` and plan files work.

## Other providers

An AKS node resource group is held by its cluster, never swept ([COMPATIBILITY.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/azure/COMPATIBILITY.md)).
