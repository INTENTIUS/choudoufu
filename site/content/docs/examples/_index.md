# Examples

Each example is a small project in the repository that you can clone and run.

| Example | What it shows |
|---|---|
| [Terralith migration](https://github.com/INTENTIUS/choudoufu/blob/main/live/TERRALITH-MIGRATION.md) | Splitting one large configuration into per-team estates by retagging, with no state surgery, and the measured plan-time difference |
| [`examples/ci-pipelines`](https://github.com/INTENTIUS/choudoufu/blob/main/examples/ci-pipelines/README.md) | The five CI jobs an estate needs, generated for GitHub, Forgejo and GitLab |
| [`examples/pipeline-governance`](https://github.com/INTENTIUS/choudoufu/blob/main/examples/pipeline-governance/README.md) | Branch rules that require the check and plan jobs and put an apply behind a reviewer |
| [`examples/record-store-bucket`](https://github.com/INTENTIUS/choudoufu/blob/main/examples/record-store-bucket/README.md) | A correct record store bucket, and the IAM policy for an estate's role |
| [`examples/record-store-cluster`](https://github.com/INTENTIUS/choudoufu/blob/main/examples/record-store-cluster/README.md) | Records namespace and Roles for an estate kept in a cluster |
| [`examples/cross-estate-dependency`](https://github.com/INTENTIUS/choudoufu/tree/main/examples/cross-estate-dependency) | Two estates, one reading a value off the other's live resource |
| [`examples/live-mv-workbench`](https://github.com/INTENTIUS/choudoufu/tree/main/examples/live-mv-workbench) | A notebook that splits a configuration by retagging, against the local emulator |
