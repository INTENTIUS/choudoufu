# Cohort notes

This directory holds one hand-written notes file per verification cohort and
nothing else. The cohorts themselves - `versions.tf`, `locals.tf`,
`estate.chdf.hcl`, the coverage file, `supporting.tf` and `GENERATED.md` - are
no longer committed. They are rendered at run time, into the run's own work
directory, and thrown away afterwards (issue #699).

Render them:

```
env -u PWD go run ./tools/estate-gen -all -out /tmp/estate-gen
```

or one cohort:

```
env -u PWD go run ./tools/estate-gen -cohort lambda -out /tmp/estate-gen/lambda
```

`-all` reads every cohort's pinned `-types` roster from
[internal/live/cohorts](../../../internal/live/cohorts/cohorts.go), which is
where each deleted `GENERATED.md`'s regeneration command now lives, and shares
one provider-schema acquisition across the set. It is what
`TestCohortAcceptance` (internal/live/acceptance) invokes before it applies
anything, the same way `live/e2e/terralith-scale/run.sh` invokes
`tools/terralith-gen` into `$WORK/gen`.

## Why the trees went

They were generator output, committed. Every working copy accumulated an
ignored `.terraform/` inside each of the 31 rendered directories,
`.gitignore` carried a scoped exception block to manage exactly that, a
regeneration was a 213-file diff nobody read, and the identity golden pinned
704 identities that no fixture author had written. `tools/terralith-gen` had
already chosen the other model. Nothing was lost in the move: 30 of the 31
committed trees regenerated byte-identical to the generator's own output on
2026-09-06, and the one that did not
(`route53-cloudfront`, an `aws_route53_zone_association` argument the
committed tree omitted) was the committed copy being stale, not the generator
being wrong.

## What stayed

The notes. Ratification evidence, per-type verdicts, emulator findings, the
"Untaggable types" and "Floci coverage" sections that `live/flocicap.go`,
`live/residue.go`, `internal/live/stamp`'s cohort files and
`internal/live/discovery`'s live tests all cite by path. Those are hand
rulings; the generator never wrote them and never rewrote them, and deleting
them would have thrown away the reasoning that admitted several hundred types.

`live/e2e/estates/example/README.md` is the shape a new cohort's notes start
from; it never rendered configuration of its own.
