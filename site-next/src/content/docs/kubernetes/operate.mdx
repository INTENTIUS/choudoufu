## Rename

Renaming a block rewrites the address annotation, through `live-mv <old> <new>` or the next apply. Moving an object to another estate is a relabel with `live-mv -from-estate` or `kubectl label --overwrite`.

### Records

A team keeps records in the cluster, with no AWS account:

```hcl
record_store "kubernetes" {}
```

Each record is one Secret in `tofu-records-<estate>`. Create that namespace yourself. `choudoufu live-cluster` checks access, encryption and the boundary policy, and names each fix.

## Remove

An object with your label that no block declares is proposed for deletion. Owner-referenced objects, control-plane objects and a live Helm release's objects are excluded first.

## Scale

Does not apply: each instance's name is already in its key.

## Plan, review, apply

As on [AWS](/choudoufu/aws/operate/): the approval check belongs to the engine.

## From CI

The same five jobs as on [AWS](/choudoufu/aws/operate/).

## Two runs at once

Server-side apply settles it. The loser gets a 409 naming the other manager and the contested fields. [OPERATE.md](https://github.com/INTENTIUS/choudoufu/blob/main/live/kubernetes/OPERATE.md) has the rest.
