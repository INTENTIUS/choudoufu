# Rulings

Dated records of decisions this fork has already made, and of the
measurements they rest on.

choudoufu is one maintainer's fork. There is no comment period, no review
board and no acceptance step: a document lands here once the decision is
made, not to solicit agreement on a proposal. Read a file here as settled
unless a later one supersedes it — several already do, and each says so in
its opening lines.

A ruling is cited by path from the code it governs, so the reasoning behind
a refusal or a default is reachable from the place it takes effect. Those
citations are load-bearing; a file here is not renamed or removed without
updating them.

Most files carry numbers. Where they do, the commands that produced them are
included so the measurement can be rerun rather than trusted, and the date
in the filename is the date the numbers were taken.

Upstream OpenTofu runs its own RFC process, and its documents live in that
project at
[`opentofu/opentofu`](https://github.com/opentofu/opentofu/tree/main/rfc).
Where this fork's code cites one, it links there. This directory is not that
and does not follow it.
